This report is the 1.1 record of CD-REL-16 for Cobblemon Dynamics `1.1.0`, built from the branch `v11-farming`. It lists the
checks that ran on the branch, with their results, and the checks that wait. CD-REL-16 needs every `MUST` and `MUST NOT` row
